Kitchen Wall Privacy Policy

Last updated: November 5, 2026

Kitchen Wall is a private household app. It is not offered to the public.

What data Kitchen Wall accesses

With the account owner's permission, Kitchen Wall accesses Google Calendar events (the https://www.googleapis.com/auth/calendar.events scope) for the owner's own calendars.

How the data is used

Calendar events are used only to display them on a wall screen in the home, and to create, edit or delete events when a household member asks it to.

Storage and sharing

Data stays on the household's own home server. It is not sold, shared with third parties, used for advertising, or used to train AI models. Access tokens are stored encrypted on that server.

Google API Services User Data Policy

Kitchen Wall's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
